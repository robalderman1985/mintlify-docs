## Prerequisites

- A Rob-labs account
- An API key

## Get started

<Steps>
  <Step title="Sign in to Rob-labs">
    Sign in to your Rob-labs account.
  </Step>
  <Step title="Create an API key">
    Create an API key to authenticate your requests. Keep it secret and never commit it to source control.
  </Step>
  <Step title="Make your first request">
    Send a request to the Rob-labs API with your API key. See the [API reference](/api-reference/introduction) for details.
  </Step>
</Steps>
